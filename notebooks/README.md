# Notebooks

This folder contains notebooks for interactive analysis and documentation of the palynomorph detection project. It currently focuses on exploration, and will later include a demo notebook that walks through the full preprocessing and modeling pipeline. The notebooks are intended for exploratory use and are not part of the production pipeline.

## Contents

- exploration.ipynb: Core EDA notebook containing visualizations of the annotation size and class distributions, slide-level metadata, focus metrics, and more.

This directory contains scripts and utilities for preprocessing NDPI/NDPA slide data into machine learning-ready formats. The preprocessing pipeline consists of several stages, each with a dedicated script:

## Stages of Preprocessing

1. **generate_tiles.py**
   - Converts raw NDPI (image) and NDPA (annotation) files into HDF5 (.h5) files containing image tiles and their annotations.
   - Tiles are generated by subdividing annotated regions (ROIs) into a grid, extracting image crops and annotation data for each tile.
   - Output: H5 files with per-tile image data and bounding box/label annotations.

2. **focus_stack.py** / **mip.py**
   - `focus_stack.py`: For each tile, computes a focus-stacked image by selecting, for each pixel, the focal plane with the highest Laplacian of Gaussian (LoG) response. The result is saved in the H5 file.
   - `mip.py`: For each tile, computes a maximum intensity projection (MIP) across the z-stack, collapsing the stack into a single 2D image per tile.
   - Output: Additional datasets (e.g., `focus_stacked`, `maximum_intensity_projection`) added to each tile group in the H5 files.

3. **split_data.py**
   - Splits the processed H5 files into train, validation, and test sets (default 70/15/15 split).
   - Reads all H5 files in the processed directory, shuffles, and assigns them to splits.
   - Output: JSON file listing image names in each split.

4. **export_coco.py**
   - Converts the processed and split data into the COCO object detection format.
   - Supports multiple extraction modes (focus stack, best plane, specific planes, etc.).
   - Outputs COCO-format JSON annotation files and organizes images into train/val/test folders, with an optional dataset.yaml for YOLO.

## Example Pipeline

1. Run `generate_tiles.py` to create H5 tile datasets from raw NDPI/NDPA files.
2. Run `focus_stack.py` or `mip.py` to add focus-stacked or MIP images to each tile.
3. Run `split_data.py` to create train/val/test splits.
4. Run `export_coco.py` to export the dataset in COCO format for model training.

## Notes

- Each script is modular and can be run independently.
- See each script for detailed usage instructions and options.
- The pipeline is designed for flexibility in tile extraction, image processing, and export formats.

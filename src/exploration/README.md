This directory contains a single notebook that consolidates the exploration, analysis, and plotting workflows for NDPI/NDPA slide data and derived tile datasets. The preprocessing pipeline must be run before generating plots that depend on tiles.

## Notebook

- **exploration_plots.ipynb**: One-stop notebook for all exploration plots, including class distributions, annotation counts/sizes, annotation density, staining metadata, slide/ROI sizes, split sanity checks, and focus exploration for tile stacks.

## Usage
- Open the notebook, set paths in the Configuration section, and run the sections you need.
- Outputs are saved under output/exploration by default.
